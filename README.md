# Прогнозирование конечных свойств композиционных материалов

Выпускная квалификационная работа по курсу «Наука о данных: профессиональный уровень (Data Science PRO)».

Автор: Москаленко Георгий Михайлович.

## Задачи

- Прогноз модуля упругости при растяжении, ГПа.
- Прогноз прочности при растяжении, МПа.
- Оценка соотношения матрица–наполнитель с помощью нейронной сети Keras.
- Приложение Flask для применения обученных моделей.

## Быстрый запуск

Для демонстрации нужен Python 3.13. Модели уже обучены, зависимости приложения включены в папку `_vendor`.

В Windows дважды нажмите `START_WINDOWS.cmd`. Либо откройте терминал в папке проекта и выполните:

```console
python app.py
```

Откройте http://127.0.0.1:8765 и оставьте окно запуска открытым. В режиме «Свойства» вводятся 11 параметров и рассчитываются два механических свойства. В режиме «Соотношение» вводятся 12 параметров, включая известные или желаемые механические свойства, и рассчитывается соотношение матрица–наполнитель. Для пробного расчёта поля заполнены медианными значениями. Нажмите «Рассчитать прогноз». Для остановки приложения нажмите Ctrl+C в терминале.

## Данные и методы

Исходные файлы `data/X_bp.xlsx` и `data/X_nup.xlsx` предоставлены в задании курса. Объединение по индексу методом INNER даёт 1023 наблюдения и 13 столбцов. Пропуски и дубликаты отсутствуют; 17 строк второго файла не вошли в объединение.

Разведочный анализ включает описательную статистику, средние значения и медианы, гистограммы, диаграммы размаха, попарные диаграммы рассеяния и корреляции.

Данные разделены на обучающую и тестовую выборки в отношении 70/30: 716 и 307 строк, `random_state=42`. Границы фильтрации по межквартильному размаху (IQR), заполнение пропусков и масштабирование MinMaxScaler определяются только по обучающей части, отдельно в каждом блоке перекрёстной проверки. Тестовая выборка не фильтруется. Угол нашивки 0/90 не проверяется фильтром IQR. Из полной обучающей выборки исключены 53 строки, для обучения регрессий осталось 663.

Сравниваются LinearRegression, Ridge, Lasso, RandomForestRegressor и GradientBoostingRegressor. Гиперпараметры подбираются GridSearchCV с 10 блоками; критерий выбора — RMSE перекрёстной проверки. Дополнительно рассчитаны контрольная модель, прогнозирующая среднее значение целевой переменной по обучающей выборке, и Ridge без фильтрации выбросов.

Для соотношения обучена сеть Keras с архитектурой 12–16–8–1, ReLU, линейным выходом, Adam и L2-регуляризацией 0,001. Внутри обучающей выборки выделены 572 строки для обучения и 144 для валидации; после IQR для обучения осталось 523 строки. Архитектура и эпоха выбраны по валидационной выборке. Лучшая эпоха — 70, выполнено 90 эпох. RMSE на валидационной выборке — 0,7794.

| Задача | Модель приложения | R² | MAE | RMSE |
|---|---|---:|---:|---:|
| Модуль упругости при растяжении, ГПа | Lasso | −0,0200 | 2,5605 | 3,1833 |
| Прочность при растяжении, МПа | GradientBoostingRegressor | 0,0180 | 378,1158 | 468,9466 |
| Соотношение матрица–наполнитель | Keras | −0,0402 | 0,7742 | 0,9442 |

Результаты показывают слабую предсказательную способность на данном разделении. Нейросеть уступает контрольной модели, у которой RMSE составляет 0,9259. Оценка соотношения не подтверждает оптимальность состава и не гарантирует получение заданных свойств. Прогнозы не заменяют физические испытания.

## Повторение исследования

Полный расчёт выполнен в Google Colab: Python 3.13.15, pandas 2.2.3, NumPy 2.3.5, scikit-learn 1.8.0, TensorFlow 2.21.0, Keras 3.15.1. Длительность сохранённого запуска — 109,34 секунды. Версии и параметры записаны в `reports/run_manifest.json`. Повторное обучение может дать небольшие численные отличия из-за оборудования.

Для полного обучения на компьютере выполните в Windows:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe train.py
.\.venv\Scripts\python.exe verify.py
.\.venv\Scripts\python.exe make_research_notebook.py
```

Либо откройте `START_COLAB.ipynb` в Google Colab и загрузите архив проекта с папкой `vkr_composites` внутри. Готовое приложение можно демонстрировать без повторного обучения.

Для проверки готового приложения выполните `python verify.py`. Проверки охватывают вычисление прогнозов и обработку корректных и ошибочных запросов.
