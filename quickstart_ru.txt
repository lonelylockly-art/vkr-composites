БЫСТРЫЙ ЗАПУСК ГОТОВОГО ПРИЛОЖЕНИЯ
1. Полностью распакуйте итоговый ZIP.
2. В папке vkr_composites дважды нажмите START_WINDOWS.cmd.
3. Откройте http://127.0.0.1:8765. Окно запуска оставьте открытым.
4. В режиме «Свойства» нажмите «Рассчитать прогноз».
5. Переключитесь на соотношение и повторите расчёт.
6. Для остановки вернитесь в окно запуска и нажмите Ctrl+C.
Если py недоступен, откройте папку в VS Code и выполните в терминале python app.py.
Установка дополнительных библиотек для приложения не нужна.
